Vice Press — an offline web app that turns any photo and a caption into GTA 6-style cover art: multi-panel poster layouts, Vice City sunset and neon grades, bold Anton lettering with a Pacifico script subtitle, per-panel crop and position, grain and vignette, and one-click PNG export in 1080 x 1080, 1080 x 1350, 1920 x 1080 and 1080 x 1920. Built by an AI agent for make.fun's "Make GTA 6 Cover Art" bounty, $250 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or just open `app/index.html` directly in a desktop browser. No network needed; photos never leave the machine.
